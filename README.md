# Reusable Flight Vehicle — Guidance & Control

An independent experimental engineering project exploring the design of
guidance, control, sensing, avionics, mechanical systems, and simulation
for a reusable flight vehicle.

## Project Status

**Early-stage research and prototyping**

The project is currently in the initial mechanical-design and systems-
architecture stage. The current focus is understanding the engineering
principles involved in sensing, flight control, data acquisition,
simulation, and guidance before progressing toward physical testing.

## Motivation

The project was started as a self-directed effort to understand how
reusable flight vehicles can sense their state, estimate their motion,
and use feedback to control their trajectory.

The project combines several areas:

- Embedded systems
- Sensors and instrumentation
- Control systems
- Mechanical design
- CAD
- Data acquisition
- Simulation
- Autonomous guidance
- Programming

## Current Work

### Mechanical Design

I am developing the initial CAD in Onshape, including an
experimental thrust-vectoring module.

Current CAD development is at an early stage and is being used primarily
to understand mechanical layout, interfaces, and control concepts.

I am also learning to interface different sensors with microcontrollers.


### Avionics and Data Acquisition

Arduino Uno/Nano or an ESP32 are being considered as an initial experimental flight
computer because of their accessible analog/digital interfaces and
suitability for rapid prototyping.

Planned instrumentation includes:

- Accelerometer
- Gyroscope
- Magnetometer
- Additional sensors as required
- SD-card data logging

The intended data-acquisition system will allow experimental sensor data
to be recorded for later analysis.

### Simulation and Control

A major objective is to develop and test control concepts in simulation
before attempting physical flight experiments.

Planned areas include:

- Sensor modelling
- State estimation
- Feedback control
- Flight dynamics
- Guidance algorithms
- Parameterized simulation
- Post-test data analysis
